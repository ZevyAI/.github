# Security Policy

## Reporting vulnerabilities

Do not open public issues for security vulnerabilities.

Please use GitHub's private vulnerability reporting for the affected repository.
If unavailable, contact the ZevyAI maintainers directly and include:

- affected component or service
- impact and severity estimate
- reproduction details
- possible mitigation

## Response targets

- Initial acknowledgement: within 48 hours
- Triage and remediation plan: after validation
- Disclosure: coordinated after patch availability
