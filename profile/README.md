# ZevyAI

**One chat. A roster of specialists. All working in parallel.**

ZevyAI builds a multi-agent operating layer for modern teams: orchestration, workflow automation, secure integrations, and production operations in one stack.

## What We Build

- Multi-agent orchestration and delegated execution
- Voice, workflow, and integration automation
- Enterprise-grade control plane, observability, and operations
- Cross-surface product experiences (web, back office, desktop, mobile)

## Core Repositories

- [`assistant-platform`](https://github.com/ZevyAI/assistant-platform) — primary monorepo
- [`assistant-api`](https://github.com/ZevyAI/assistant-api) — API-focused repository
- [`zevy-webapp`](https://github.com/ZevyAI/zevy-webapp) — web product surface
- [`zevy-back-office`](https://github.com/ZevyAI/zevy-back-office) — internal operator tooling
- [`zevy-connector-hub`](https://github.com/ZevyAI/zevy-connector-hub) — integrations and connectors
- [`zevy-memory`](https://github.com/ZevyAI/zevy-memory) — memory and retrieval services

## Principles

- Production-first engineering
- Security, reliability, and observability by default
- DB-driven configuration over hardcoded behavior
- Modular architecture with clear boundaries
